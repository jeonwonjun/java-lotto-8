# java-lotto-precourse

## 기능 요구 사항
1. 입력
- [ ] 로또 구입 금액
  - [예외] 숫자가 입력되어야 한다.(정수형 범위)
  - [예외] 1000 단위로 나누어 떨어져야한다.
  - [예외] 최소 1장(1000원) 이상 구매해야한다.
- [ ] 당첨 번호
  - 쉼표 기준으로 리스트화
  - [예외] 6개만 입력받아야 한다.
  - [예외] 숫자여야 한다.
  - [예외] 1~45까지의 범위를 가진다.
  - [예외] 다른 숫자와 중복되면 안된다.
- [ ] 보너스 번호
  - [예외] 숫자여야 한다.
  - [예외] 1~45까지의 범위를 가진다.
  - [예외] 당첨 번호와 중복되면 안된다.
     
* 사용자가 잘못된 값을 입력할 경우 ```IllegalArgumentException```을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 ```그 부분을 다시 입력받는다.```
  - ```IllegalArgumentException```, ```IllegalStateException``` 등과 같은 명확한 유형을 처리한다.
 
2. 로또 실행
- [ ] 랜덤한 6자리의 로또를 발행한다.
  - ```Randoms.pickUniqueNumbersInRange(1, 45, 6);```
  - __위 함수가 정렬되어 출력되는지 확인 필요__
- [ ] 당첨 번호와 발행한 로또 번호의 일치 갯수를 구한다.
  - [ ] 당첨 번호가 5개면 보너스 번호가 일치하는지 확인
  - [ ] 일치하는 갯수에 맞는 등수의 수를 저장한다.

3. 수익률 계산
- [ ] 저장된 당첨 등수의 수만큼 당첨금액의 합계를 구한다.
  - 총 당첨금액은 혹시 모르니 int형 보다 큰 자료형을 사용해야할 듯
- [ ] ```(총 당첨금액/로또 구입 금액)*100```으로 총 수익률을 계산한다.
  - 수익률은 소수점 둘째 자리에서 반올림한다.

4. 출력
- [ ] 발행한 로또 출력
  - [ ] Random으로 발행한 로또를 오름차순으로 출력
- [ ] 당첨 통계 출력
  - 저장된 등수의 수를 일치 갯수의 오름차순으로 출력
- [ ] 총 수익률 출력
